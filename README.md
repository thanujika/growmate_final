# 🌱 Grow Mate – Smart Agriculture Mobile Application

## 📌 Overview

**Grow Mate** is a smart agriculture mobile application designed to support farmers in Sri Lanka by improving productivity, efficiency, and access to agricultural resources. The app focuses on simplifying farming activities through digital solutions such as reminders, marketplace features, and user-friendly tools.

---

## 🎯 Objectives

* Assist farmers in managing daily agricultural tasks
* Provide timely reminders for farming activities
* Enable buying and selling of agricultural products
* Promote smart and sustainable farming practices
* Support rural farmers with accessible technology

---

## 🚀 Features

### 📅 Farming Reminders

* Schedule and manage farming tasks
* Get notifications for watering, fertilizing, harvesting, etc.

### 🛒 Agri Marketplace

* Buy and sell agricultural products بسهولة
* Connect farmers directly with buyers

### 🔍 Search & Navigation

* Easy-to-use interface with search functionality
* Quickly find products and farming resources

### 📱 User-Friendly Interface

* Clean and modern UI/UX design
* Simple navigation for all user types

### 🌍 Sustainable Goal Support

* Supports **UN Sustainable Development Goal: Zero Hunger**

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/Yadhurshini/Growmate.git
```

2. Navigate to the project folder:

```bash
cd Growmate
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the app:

```bash
flutter run
```
